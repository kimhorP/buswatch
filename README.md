# BusWatch

A Telegram bot that watches bus ticket availability so you don't have to keep refreshing the booking page.

## What it does

- **Monitors availability** — checks seat counts for the routes and departures you care about
- **Tracks changes over time** — keeps a history of seat counts, so you can see when tickets appeared or vanished
- **Alerts you** — sends a Telegram message when seats are running low, or when a departure is fully booked
